## Getting Started Playbook

Create a profile for each viewer before watching anything, so recommendations start clean. Set download quality per device in the app settings. Check the plan tier against the resolution you actually need.

Use the profile lock if a child shares the account. Read Netflix reviews about download limits and device counts, then manage devices accordingly. Review viewing activity occasionally to correct a profile that has drifted.

## Troubleshooting Common Issues

Install issues? Lower download quality when storage runs short during travel.  
Performance problems? Check the plan tier when 4K titles are unavailable.  
License/activation? Remove unused devices when playback is refused for too many streams.  
Compatibility? Update the app if downloads fail after a certificate change.  
Update failures? Verify the profile lock PIN is recorded somewhere safe.
